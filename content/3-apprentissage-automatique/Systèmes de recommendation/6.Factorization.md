\textbf{(ii) First proposition.} FM is a type of algorithm which is a combination of linear regression and matrix factorization, it aims as modeling the interactions between features using factorized parameters. By doing so, it has the ability to estimate all interactions between features even with extremely sparse data.\\

\textbf{- Naive model.} Normally, when we think of linear regression, we would think of the following formula:
$$
\hat{y}(\mathbf{x})=w_{0}+\sum_{i=1}^{n} w_{i} x_{i}
$$

This formula's advantage is that it can computed in linear time, $O(n) .$ The drawback, however, is that it does not handle feature interactions.\\

\textbf{(ii) Second proposal.}  To capture interactions, we could introduce a weight for each feature combination. This is sometimes referred to as a $2_{n d}$ ordered polynomial. The resulting model is shown below:
$$
\hat{y}(\mathbf{x})=w_{0}+\sum_{i=1}^{n} w_{i} x_{i}+\sum_{i=1}^{n} \sum_{j=i+1}^{n} w_{i j} x_{i} x_{j}
$$

\textbf{- Example.} If we let $[X]_{n \times d}$ and $[W]_{n \times n}$ which is a symmetric matrix where in rows we have the observations $x_1,..,x_n$ and in columns we have similarly $x_1,..,x_n$. The matrix $W$ aims at calculating all the interactions between the variables. The equation would look like

$$
\hat{y}(\mathbf{x})=w_{0}+ \langle w, x\rangle+ w_{1 2} x_{1} x_{2} + w_{1 3} x_{1} x_{3} + ...
$$

\textbf{- Caveats.} The problem is that we have now ended up with a $O(n^2)$ complexity. Another issue is that having categorical variables with high cardinality, we would obtain a very sparse dataset, making it harder to capture all interactions.\\

\textbf{(iv) Factorization Machine (FM).} To solve both problems Factorization Machines takes inspiration from matrix factorization, and models the feature interaction using latent factors.\\

\textbf{- Feature interactions.} Every feature $f_{i}$ has a corresponding latent factor $v_{i}$, and two features' interactions are modelled as $\left\langle\mathbf{v}_{i}, \mathbf{v}_{j}\right\rangle$, where $\langle\cdot, \cdot\rangle$ refers to the dot product of the two feature vector. If we assume its of size $k$ (this is a hyperparameter that we can tune). Then:

$$
\left\langle\mathbf{v}_{i}, \mathbf{v}_{j}\right\rangle=\sum_{f=1}^{k} v_{i, f} v_{j, f}
$$

\textbf{- New prediction.} This leads of our new equation:
$$
\hat{y}(\mathbf{x})=w_{0}+\sum_{i=1}^{n} w_{i} x_{i}+\sum_{i=1}^{n} \sum_{j=i+1}^{n}\left\langle\mathbf{v}_{i}, \mathbf{v}_{j}\right\rangle x_{i} x_{j}
$$

This is an improvement from our previous model (when we modeled each pair of interaction terms with weight $w_{i j}$ ) as the number of parameters is reduced from $n^{2}$ to $n \times k$, since $k \ll n$, which also helps mitigate overfitting issues. 




\textbf{- New formulation.} Using the naive way of formulating factorization machine results in a complexity

\begin{align}
\sum_{i=1}^n \sum_{j=i+1}^n \langle \textbf{v}_i, \textbf{v}_{j} \rangle x_{i} x_{j}
&= \frac{1}{2} \sum_{i=1}^n \sum_{j=1}^n \langle \textbf{v}_i, \textbf{v}_{j} \rangle x_{i} x_{j} - \frac{1}{2} \sum_{i=1}^n \langle \textbf{v}_i , \textbf{v}_{i} \rangle x_{i} x_{i}  \\
&= \frac{1}{2}\left(\sum_{i=1}^n \sum_{j=1}^n \sum_{f=1}^k v_{i,f} v_{j,f} x_{i} x_{j} \right)\frac{1}{2}\left( \sum_{i=1}^n \sum_{f=1}^k v_{i,f} v_{i,f} x_{i} x_{i} \right) \\
&= \frac{1}{2}\left(\sum_{i=1}^n \sum_{j=1}^n \sum_{f=1}^k v_{i,f} v_{j,f} x_{i} x_{j}  -  \sum_{i=1}^n \sum_{f=1}^k v_{i,f} v_{i,f} x_{i} x_{i} \right) \\
&= \frac{1}{2} \sum_{f=1}^{k} \left( \left(\sum_{i=1}^n v_{i,f}x_{i} \right) \left( \sum_{j=1}^n v_{j,f}x_{j} \right) - \sum_{i=1}^{n} v_{i,f}^2 x_{i}^2 \right) \\
&= \frac{1}{2} \sum_{f=1}^{k} \left( \left( \sum_{i}^{n} v_{i,f}x_{i} \right)^2  - \sum_{i=1}^{n} v_{i,f}^2 x_{i}^2 \right)
\end{align}

Note, summing over different pairs is the same as summing over all pairs minus the self-interactions (divided by two). This is the reason why the value $1 / 2$ is introduced from the beginning of the derivation.
This reformulated equation has a linear complexity in both $k$ and $n$, i.e. its computation is in $O(k n)$, substituting this new equation into the existing factorization machine formula, we end up with:
$$
\left.\hat{y}(\mathbf{x})=w_{0}+\sum_{i=1}^{n} w_{i} x_{i}+\frac{1}{2} \sum_{f=1}^{k}\left(\sum_{i}^{n} v_{i, f} x_{i}\right)^{2}-\sum_{i=1}^{n} v_{i, f}^{2} x_{i}^{2}\right)^{2}
$$

To train factorization machine, we can use a gradient descent based optimization techniques, the parameters to be learned are $\left(w_{0}, \mathbf{w}\right.$, and $\left.\mathbf{V}\right)$.

\begin{align}
\frac{\partial}{\partial\theta}\hat{y}(\textbf{x}) =
\begin{cases}
1,  & \text{if $\theta$ is $w_0$} \\
x_i, & \text{if $\theta$ is $w_i$} \\
x_i\sum_{j=1}^{n} v_{j,f}x_j - v_{i,f}x_{i}^2 & \text{if $\theta$ is $v_{i,f}$}
\end{cases}
\end{align}

\begin{itemize}
    \item Notice that $\sum_{j=1}^{n} v_{j, f} x_{j}$ does not depend on $i$, thus it can be computed independently.
    \item The last formula above, can also be written as $x_{i}\left(\sum_{j=1}^{n} v_{j, f} x_{j}-v_{i, f} x_{i}\right)$
    \item In practice, we would throw in some L2 regularization to prevent overfitting.
\end{itemize}

\textbf{- Loss function.} In a machine learning setting, factorization machine can be applied to different supervised prediction tasks:

\begin{itemize}
    \item Regression:, in this case $\hat{y}(\mathbf{x})$ can be used directly by minimizing the mean squared error between the model prediction and target value, e.g. $\frac{1}{N} \sum^{N}(y-\hat{y}(\mathbf{x}))^{2}$
    \item Classification:, if we were to use it in a binary classification setting, we could then minimize the log loss, $\ln \left(e^{-y \cdot \hat{y}(\mathbf{x})}+1\right)$, where $\sigma$ is the sigmoid/logistic function and $y \in-1,1$.
\end{itemize}

We update in the classification setting by, The predicted value $\hat{y}(\mathbf{x})$ is replaced with $x$ for making the notation cleaner.

\begin{align}
\frac{d}{dx}\left[ \ln \big(e^{-yx} + 1 \big) \right] 
&= \frac{1}{e^{-yx} + 1} \cdot  \frac{d}{dx}\left[e^{-yx} + 1 \right] \\
&= \frac{\frac{d}{dx}\left[e^{-yx} \right] + \frac{d}{dx}\left[1 \right]}{e^{-yx} + 1} \\
&= \frac{e^{-yx} \cdot \frac{d}{dx}\left[-yx \right] + 0}{e^{-yx} + 1} \\
&= \frac{e^{-yx} \cdot -y}{e^{-yx} + 1} \\
&= -\frac{ye^{-yx}}{e^{-yx} + 1} \\
&= -\frac{y}{e^{yx} + 1}
\end{align}

\textbf{(v) Implementation.}\\
\textbf{- Inputs.} Let $[X]_{n \times d}$ which is a very sparse matrix. Let $[w]_{1 \times d} \sim N(\cdot)$. Every feature vector $f_i$ of the matrix $X$ have a corresponding latent factor $v$ that is we initialize $[V]_{k \times d} \sim N(\cdot)$ where $k$ is a hyperparameter.\\

\textbf{- Updated function.} We leverage the sparse package of scipy that is it returns all the non-zero values directly. It let us updates all the weights and the $V$ matrix stepwise efficiently wrt to sparse data.

$$
\hat{y}(\mathbf{x})=w_{0}+\sum_{i=1}^{n} w_{i} x_{i}+\sum_{i=1}^{n} \sum_{j=i+1}^{n}\left\langle\mathbf{v}_{i}, \mathbf{v}_{j}\right\rangle x_{i} x_{j}
$$
