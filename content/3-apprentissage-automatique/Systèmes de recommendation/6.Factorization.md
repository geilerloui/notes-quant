# Factorization Machine

## Intro

**(i) Convert.** The first step is to convert the usual user rating matrix $u: C \times S \rightarrow R$ to a sparse structured table on the right:

![[images/3-Apprentissage automatique/10_Recommender system/6.Factorization/im1-1.png]]

**Example.** Assume we have the transaction data of a movie review system. The system records which user $u \in U$ rates a movie (item) $i \in I$ at a certain time $t \in \mathbb{R}$ with a rating $r \in \{1,2,3,4,5\}$. Let the users $U$ and items $I$ be:

$$\begin{aligned}
U =\ &\{\text{Alice (A), Bob (B), Charlie (C)}, \ldots\} \\
I =\ &\{\text{Titanic (TI), Notting Hill (NH), Star Wars (SW),} \\
&\text{Star Trek (ST), } \ldots\}
\end{aligned}$$

Let the observed data $S$ be:

$$\begin{aligned}
S = \{&(\text{A, TI, 2010-1, 5}), (\text{A, NH, 2010-2, 3}), (\text{A, SW, 2010-4, 1}), \\
&(\text{B, SW, 2009-5, 4}), (\text{B, ST, 2009-8, 5}), \\
&(\text{C, TI, 2009-9, 1}), (\text{C, SW, 2009-12, 5})\}
\end{aligned}$$

We can even extend to a bigger table by incorporating content-based information about the user. Here we have added the time variable, other movies rated, and the last movie rated:

![[images/3-Apprentissage automatique/10_Recommender system/6.Factorization/im1-2.png]]

**(ii) First proposition.** FM is a type of algorithm that combines linear regression and matrix factorization — it models the interactions between features using factorized parameters. By doing so, it can estimate all interactions between features even with extremely sparse data.

**Naive model.** Normally, linear regression would use the following formula:

$$\hat{y}(\mathbf{x}) = w_0 + \sum_{i=1}^n w_i x_i$$

This formula's advantage is that it can be computed in linear time, $O(n)$. The drawback is that it does not handle feature interactions.

**Second proposal.** To capture interactions, we could introduce a weight for each feature combination — sometimes referred to as a 2nd-order polynomial. The resulting model:

$$\hat{y}(\mathbf{x}) = w_0 + \sum_{i=1}^n w_i x_i + \sum_{i=1}^n \sum_{j=i+1}^n w_{ij}\, x_i x_j$$

**Example.** If we let $[X]_{n \times d}$ and $[W]_{n \times n}$ be a symmetric matrix, where in rows we have the observations $x_1, \ldots, x_n$ and in columns similarly $x_1, \ldots, x_n$. Matrix $W$ aims at capturing all the interactions between the variables. The equation would look like:

$$\hat{y}(\mathbf{x}) = w_0 + \langle w, x \rangle + w_{12} x_1 x_2 + w_{13} x_1 x_3 + \ldots$$

**Caveats.** The problem is that we now end up with $O(n^2)$ complexity. Another issue is that categorical variables with high cardinality yield a very sparse dataset, making it harder to capture all interactions.

**(iv) Factorization Machine (FM).** To solve both problems, Factorization Machines take inspiration from matrix factorization and model feature interactions using latent factors.

**Feature interactions.** Every feature $f_i$ has a corresponding latent factor $\mathbf{v}_i$, and the interaction of two features is modeled as $\langle \mathbf{v}_i, \mathbf{v}_j \rangle$, the dot product of the two feature vectors, of size $k$ (a tunable hyperparameter):

$$\langle \mathbf{v}_i, \mathbf{v}_j \rangle = \sum_{f=1}^k v_{i,f}\, v_{j,f}$$

**New prediction.** This leads to the new equation:

$$\hat{y}(\mathbf{x}) = w_0 + \sum_{i=1}^n w_i x_i + \sum_{i=1}^n \sum_{j=i+1}^n \langle \mathbf{v}_i, \mathbf{v}_j \rangle\, x_i x_j$$

This is an improvement over the previous model (where each pairwise interaction had its own weight $w_{ij}$): the number of parameters is reduced from $n^2$ to $n \times k$, since $k \ll n$ — which also helps mitigate overfitting.

**New formulation.** The naive way of computing the factorization machine has $O(kn^2)$ complexity; we can reformulate it to be linear:

$$\begin{aligned}
\sum_{i=1}^n \sum_{j=i+1}^n \langle \mathbf{v}_i, \mathbf{v}_j \rangle\, x_i x_j
&= \frac{1}{2} \sum_{i=1}^n \sum_{j=1}^n \langle \mathbf{v}_i, \mathbf{v}_j \rangle\, x_i x_j - \frac{1}{2} \sum_{i=1}^n \langle \mathbf{v}_i, \mathbf{v}_i \rangle\, x_i x_i \\
&= \frac{1}{2}\left(\sum_{i=1}^n \sum_{j=1}^n \sum_{f=1}^k v_{i,f}\, v_{j,f}\, x_i x_j - \sum_{i=1}^n \sum_{f=1}^k v_{i,f}\, v_{i,f}\, x_i x_i \right) \\
&= \frac{1}{2} \sum_{f=1}^k \left( \left(\sum_{i=1}^n v_{i,f} x_i\right)\left(\sum_{j=1}^n v_{j,f} x_j\right) - \sum_{i=1}^n v_{i,f}^2 x_i^2 \right) \\
&= \frac{1}{2} \sum_{f=1}^k \left( \left(\sum_{i=1}^n v_{i,f} x_i\right)^2 - \sum_{i=1}^n v_{i,f}^2 x_i^2 \right)
\end{aligned}$$

Note: summing over distinct pairs is the same as summing over all pairs minus the self-interactions (divided by two) — this is why the factor $1/2$ is introduced from the beginning of the derivation. This reformulated equation has linear complexity in both $k$ and $n$, i.e. $O(kn)$. Substituting it into the FM formula, we get:

$$\hat{y}(\mathbf{x}) = w_0 + \sum_{i=1}^n w_i x_i + \frac{1}{2} \sum_{f=1}^k \left( \left(\sum_{i=1}^n v_{i,f} x_i\right)^2 - \sum_{i=1}^n v_{i,f}^2 x_i^2 \right)$$

To train the factorization machine, we use gradient-descent-based optimization; the parameters to learn are $(w_0, \mathbf{w}, \mathbf{V})$:

$$\frac{\partial}{\partial \theta} \hat{y}(\mathbf{x}) = \begin{cases}
1, & \text{if } \theta = w_0 \\
x_i, & \text{if } \theta = w_i \\
x_i \sum_{j=1}^n v_{j,f} x_j - v_{i,f} x_i^2, & \text{if } \theta = v_{i,f}
\end{cases}$$

- Note that $\sum_{j=1}^n v_{j,f} x_j$ does not depend on $i$, so it can be computed once, independently.
- The last case above can also be written as $x_i\left(\sum_{j=1}^n v_{j,f} x_j - v_{i,f} x_i\right)$.
- In practice, we would add some L2 regularization to prevent overfitting.

**Loss function.** In a machine learning setting, factorization machines can be applied to different supervised prediction tasks:
- **Regression.** $\hat{y}(\mathbf{x})$ is used directly, minimizing the mean squared error between the model prediction and target value: $\frac{1}{N}\sum^N (y - \hat{y}(\mathbf{x}))^2$.
- **Classification.** For binary classification, we minimize the log loss $\ln\left(e^{-y \cdot \hat{y}(\mathbf{x})} + 1\right)$, where $\sigma$ is the sigmoid/logistic function and $y \in \{-1,1\}$.

For the classification setting, denoting $\hat y(\mathbf x)$ simply as $x$ for cleaner notation:

$$\begin{aligned}
\frac{d}{dx}\left[\ln\left(e^{-yx} + 1\right)\right]
&= \frac{1}{e^{-yx}+1} \cdot \frac{d}{dx}\left[e^{-yx}+1\right] \\
&= \frac{\frac{d}{dx}\left[e^{-yx}\right] + \frac{d}{dx}[1]}{e^{-yx}+1} \\
&= \frac{e^{-yx} \cdot \frac{d}{dx}[-yx] + 0}{e^{-yx}+1} \\
&= \frac{e^{-yx} \cdot (-y)}{e^{-yx}+1} \\
&= -\frac{y\, e^{-yx}}{e^{-yx}+1} \\
&= -\frac{y}{e^{yx}+1}
\end{aligned}$$

**(v) Implementation.**

**Inputs.** Let $[X]_{n \times d}$ be a very sparse matrix. Let $[w]_{1 \times d} \sim N(\cdot)$. Every feature $f_i$ of matrix $X$ has a corresponding latent factor $v$, i.e. we initialize $[V]_{k \times d} \sim N(\cdot)$, where $k$ is a hyperparameter.

**Update function.** We leverage scipy's sparse package, which returns all non-zero values directly, letting us update all weights and the $V$ matrix stepwise, efficiently with respect to sparse data:

$$\hat{y}(\mathbf{x}) = w_0 + \sum_{i=1}^n w_i x_i + \sum_{i=1}^n \sum_{j=i+1}^n \langle \mathbf{v}_i, \mathbf{v}_j \rangle\, x_i x_j$$
