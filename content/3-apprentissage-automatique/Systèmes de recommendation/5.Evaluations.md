\subsubsection{Root Mean Square Error (RMSE)}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

The common methodology is to take a piece of the matrix and use it as the test data set. We actually know some of those rating so we can use them and compute a score.


![[eval-1.png]]



\textbf{Definition (RMSE).} 
$$
\boxed{RMSE = \sqrt{\frac{\sum_{(x, i) \in T}\left(r_{x i}-r_{x i}^{\star}\right)^{2}}{N}}}
$$
Where $N = |T|$, $r_{xi}$ is the predicted rating and $r_{xi}^{\star}$ is the actual rating\\

\textbf{Problems with RMSE.} RMSE misses the point of why we implement RS in the first place. Remeber the goal of RS is not to predict the rating of a user but recommend items to the user that he might buy or listen to. So if you predict with the highest score you might end up with problems
\begin{itemize}
    \item \textbf{Prediction Diversity:} prediction are too similar to each other. For example the user liked the first Harry Potter. The set of most similar might be the other Harry Potter movies which is not a very diverse set of movies.
    \item \textbf{Prediction context:} The same users migth be operating in different context. For example, let's say the user is traveling in patagonia so he looks for a lot of book on pantagonia. Then when he get back to patagonia he is not interested anymore about this topic
    \item \textbf{Order of predictions:} Example, for CDs or books or movies, you want to recommend items that are earlier in the sequence rather than the last one. For example, After the user has watched the first HP he might want to see the second one and not the third.
\end{itemize}

\subsubsection{Precision and Recall at top $k$}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\textbf{Motivation.} We have a website where people post pictures. They can rate pictures on range of 1 to 5 point. Where 1 stands for the user disliking the it and 5 totally like it. First let's write down the true values

![[images/3-Apprentissage automatique/10_Recommender system/5.Evaluation/im1-1.png]]


Then our model predict the next data:

![[images/3-Apprentissage automatique/10_Recommender system/5.Evaluation/im1-2.png]]


Similar to what we have encountered in ML we can compute the recall,accuracy and precision. By first noting that $TP = 2, TN = 2, FP = 2, FN = 0
$. Which let us calculate

\begin{itemize}
    \item $Accuracy = \frac{(2+2)}{6}=0.67 \Rightarrow 67\%$ accuracy 
    \item $Precision = \frac{2}{(2+2)}=0.5 \Rightarrow 50\%$ precision 
    \item $Accuracy = \frac{2}{(2+0)}=1 \Rightarrow 100\%$ recall 
\end{itemize}

![[images/3-Apprentissage automatique/10_Recommender system/5.Evaluation/im1-5.png]]


The problem with this approach is that typically the user did not hae any experience with the picture of a "cat". As such shall it be a false positive or true positive ? We must resort to a novel solution.\\


\textbf{Definition (Relevant).} This is the pictures that the user already liked.\\


\textbf{Definition (Recommended).} This is the pictures that are in the predicted list\\

\textbf{Definition (Precision and Recall @ $k$).} To start off we have to sort the predictions by increasing order. Formally define $\omega(r)$ as the item at rank $r$, $I[\cdot]$ is the indicator function, and $I_u$ is the set of held-out items that user $u$ clicked on. 

$$
\begin{aligned}
Precision &= \frac{(\text{recommended} \cap \text{relevant})}{recommended}\\
Recall &= \frac{(\text{recommended} \cap \text{relevant})}{relevant} \\
\operatorname{Recall@R(u,\omega )&=\frac {\sum _{r=1}^{R}\mathbb {I}[\omega (r)\in I_{u}]}{\operatorname {min}(M,|I_{u}|)}}
\end{aligned}
$$

\textbf{Example (Continued).} We take $k=3$ in our example that we then sort. Where we have two "Relevant": "Car" and "Girl". Regarding the recommended all three have been predicted.

$$
Precision = \frac{2}{3}=0.67 \quad Recall = \frac{2}{2} = 1
$$

![[images/3-Apprentissage automatique/10_Recommender system/5.Evaluation/im1-3.png]]


\textbf{Example (Continued 2).} We have two relevant (The picture the user likes in the initial data) "car" and "girl". Along with two recommended "car" and "girl".

$$
Precision = \frac{2}{2}=1 \quad Recall = \frac{2}{2} = 1
$$

![[images/3-Apprentissage automatique/10_Recommender system/5.Evaluation/im1-4.png]]


\textbf{Definition (Truncated Discounted Cumulative Gain (DCG)).} 

\begin{itemize}
    \item Motivation. With the Recall or Precision @ $k$ we consider all items ranked within the first $R$ to be equally important.
    \item Formula.
    $$
DCG@R(u, w) = \sum_{r=1}^{R} \frac{2^{1_{w(r) \in I_u}} - 1}{log(r+1)}
$$
\end{itemize}



\textbf{Definition (Normalized discounted cumulative gain (NDCG@r)).} NDCG@r is the DCF@r linearly normalized to $[0,1]$ after dividing by the best possible DCG@r, where all the held-out items are ranked at the top.\\

\textbf{Definition (Mean average precision (MAP)).} 

$$
MAP = \frac{\sum \text{ratings of recommended items}}{\text{N recommended items}}
$$


\textbf{Example.} With this model we don't care about negative results. And as we move from left to right we cound on the denominator the positive results.

$$
MAP = \frac{(1+0.67+0.75+0.67)}{4} = 0.77 \Rightarrow 77\%
$$
