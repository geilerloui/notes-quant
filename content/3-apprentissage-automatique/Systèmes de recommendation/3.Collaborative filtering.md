# Collaborative Filtering

## Introduction

**Definition (Collaborative Filtering).** We consider a user $x$ and a group of $N$ other users whose ratings are "similar" to $x$'s ratings. Typically, if you do movie recommendation, they will like and dislike the same types of movies. We call this set of users the neighborhood of $x$. Next we find other movies that are liked by a lot of users in that neighborhood, and we recommend them to user $x$. The key trick is to find the neighborhood of user $x$.

![[images/3-Apprentissage automatique/10_Recommender system/3.Collaborative filtering/intro-1 1.png|211]]

**Complexity.** The most expensive step is finding the $k$ most similar users (or items). Typically of size

$$\sim O(|U|)$$

where $|U|$ is the size of the utility matrix. Alternatives could be considered, such as Nearest-Neighbor search in high dimension (LSH), Clustering, or Dimensionality Reduction.

**Pros and cons.** The pros are summarized in one sentence — it works for any kind of item, no feature selection is needed.

In contrast the cons are multiple:
- **(i) Cold start** — we need enough users in the system to find a match.
- **(ii) Sparsity** — the user/rating matrix is sparse, so it is hard to find users that have rated the same items.
- **(iii) First rater** — we cannot recommend an unrated item.
- **(iv) Popularity bias** (aka the "Harry Potter Effect") — it tends to recommend popular items, mostly because if a movie or book is well known, most users will rate it well, which implies that CF will recommend it to anyone.

## Nearest-Neighbors Methods aka Memory-based Methods

### User Similarity — User-User CF

**Motivation.** Consider users $\mathbf{x}$ and $\mathbf{y}$ with rating vectors $\mathbf{r}_X$ and $\mathbf{r}_Y$. We need to define a similarity metric $sim(\mathbf{x}, \mathbf{y})$ that captures the intuition that $sim(A,B) > sim(A,C)$, as in the matrix below.

![[images/3-Apprentissage automatique/10_Recommender system/3.Collaborative filtering/memory-1.png]]

**Option 1 — Jaccard Similarity.**

$$\boxed{\operatorname{sim}(A, B) = |r_A \cap r_B| / |r_A \cup r_B|}$$

*Example.* In the example matrix we note that between users $A$ and $B$ there is only one common movie and five in total. Thus we get $sim(A,B) = 1/5$. By the same reasoning we can say that $sim(A,C) = 2/4$, which implies $sim(A,B) < sim(A,C)$ — the opposite of what we stated in the motivation paragraph.

*Drawbacks.* It does not take into account how much users liked the movies, and it doesn't follow our initial intuition for the similarities.

**Option 2 — Cosine Similarity.**

$$\boxed{\operatorname{sim}(A, B) = \cos(r_A, r_B)}$$

*Example.* To compute the cosine similarity we first have to replace all unknown values with zero. Similarly to option 1, we get $\operatorname{sim}(A,B) = 0.38$, $\operatorname{sim}(A,C) = 0.32$. It captures the fact that $sim(A,B) > sim(A,C)$, but not by much.

*Drawbacks.* It treats missing ratings as negative ratings. We used zero to fill the blanks, but on a 0-to-5 scale, 0 is the worst possible rating — we have effectively assumed that if a user has not rated a movie, they gave it a rating of zero, which is a bad assumption, especially with user $A$ who likes Harry Potter 1.

**Option 3 — Centered Cosine aka Pearson Correlation.**

To solve the core issue of cosine similarity we normalize the ratings by subtracting the row mean, then compute the similarity by cosine:

$$\boxed{\operatorname{sim}(A, B) = \cos(r_A, r_B)}$$

*Example.* For the first row we get $10/3$, then the second row $14/3$, giving an updated table.

![[images/3-Apprentissage automatique/10_Recommender system/3.Collaborative filtering/memory-2.png]]

We can notice that the rating for Star Wars has become a negative rating, and of course we treat the blank values as zeroes. On top of that, each row now sums to zero — zero is now the average rating. So a positive rating now means a user liked a movie more than average, and a negative rating means they liked it less than average.

Finally we compute this transformed matrix with the cosine similarity: $\operatorname{sim}(A,B) = \cos(r_A, r_B) = 0.09$, $\operatorname{sim}(A,C) = -0.56$ — now we have a big gap between the two similarities. We have captured the property that $sim(A,B) > sim(A,C)$.

*Advantages.* It treats the missing rating as "average". It is also a nice way to handle "tough raters" and "easy raters" — users who always give bad scores and those who do the opposite.

**Rating Predictions.**

Let $\mathbf{r}_X$ be the vector of user $\mathbf{x}$'s ratings. Let $N$ be the set of $k$ users most similar to $\mathbf{x}$ who have also rated item $i$. The prediction for user $\mathbf{x}$ and item $i$ has two options:

$$\begin{aligned}
\text{Option 1.} &\quad r_{xi} = \frac{1}{k} \sum_{y \in N} r_{yi} \\
\text{Option 2.} &\quad r_{xi} = \frac{\sum_{y \in N} s_{xy}\, r_{yi}}{\sum_{y \in N} s_{xy}}
\end{aligned}$$

where $s_{xy} = sim(x,y)$.

### Item-Item CF

**Motivation.** So far we have focused on User-User collaborative filtering. Another view is Item-Item CF: for an item $i$, we want to find other similar items, and estimate the rating for item $i$ based on the ratings of similar items. We can use the same similarity metrics and prediction functions as in the user-user model:

$$\boxed{r_{xi} = \frac{\sum_{j \in N(i;x)} s_{ij} \cdot r_{xj}}{\sum_{j \in N(i;x)} s_{ij}}}$$

where $s_{ij}$ is the similarity of items $i$ and $j$, $r_{xj}$ is the rating of user $x$ on item $j$, and $N(i;x)$ is the set of items rated by $x$ similar to $i$.

*Example.* We set the neighborhood size to $|N|=2$: we look at the two nearest neighbors of item $i$. We plot the utility matrix of movies/users relationship — blank cells are unknown ratings, yellow cells are ratings from 1 to 5. Our goal is to estimate the rating of movie 1 for user 5 (in red).

The first step is to take movie 1 and find other movies similar to it, using the Pearson correlation. Recall the two steps of the correlation: (i) we subtract the mean rating $m_i$ from each movie $i$, i.e. $m_1 = (1+3+5+5+4)/5$, so row 1 becomes $[-2.6, 0, -0.6, 0, 0, 1.4, 0, 0, 1.4, 0, 0.4, 0]$; (ii) we compute the cosine similarities between rows. Finally we note that the two most similar movies are movies 3 and 6.

![[images/3-Apprentissage automatique/10_Recommender system/3.Collaborative filtering/memory-3.png]]

Secondly, we apply the weighted average formula:

$$r_{15} = \frac{0.41 \times 2 + 0.59 \times 3}{0.41 + 0.59} = 2.6$$

Thus, the missing rating is $2.6$.

**Item-Item vs User-User.** In theory, those two approaches are dual of each other. In practice, however, item-item generally outperforms user-user in many use cases. Items are typically simpler than users — they belong to a small set of "genres", while users have varied tastes. Item similarity is more meaningful than user similarity.

## Matrix Factorization aka Latent Factor Models

### Singular Value Decomposition (SVD)

**Definition (SVD for RS).** Recall the formula of SVD:

$$\mathbf{A} = \mathbf{U} \mathbf{\Sigma} \mathbf{V}^T$$

We can think of the elements of this matrix as the "concepts", aka latent dimensions, aka latent factors.

**Input.** In rows we have a set of users, divided into those who enjoy SciFi movies and those who prefer Romance movies.

![[images/3-Apprentissage automatique/10_Recommender system/3.Collaborative filtering/svd-1.png]]

Plugging the matrix into Python code, we get:

![[images/3-Apprentissage automatique/10_Recommender system/3.Collaborative filtering/svd-2.png]]

There are three elements to consider:
- **$U$, user-to-concept matrix.** On the rows we have the users and on the columns the "concepts" — a summary of the categories of the movies. We say the last column is noise.
- **$\Sigma$, strength of every concept.** It tells us the SciFi concept is the most important.
- **$V$, movie-to-concept matrix.** On the columns we have the movies and on the rows the concepts. We argue that the last row is noise.

**How to reduce the dimensionality?** It suffices to remove the row/column which has the lowest singular value.

![[images/3-Apprentissage automatique/10_Recommender system/3.Collaborative filtering/svd-5.png]]

**How to query?** We can project a query $q$ (a new user) into the concept space by projection. Compactly:

$$q_{concept} = q \cdot V$$

The output yields the strength of each concept for a particular query vector. Here the SciFi concept stands out of the matrix factorization.

![[images/3-Apprentissage automatique/10_Recommender system/3.Collaborative filtering/svd-3.png]]

We can note below an interesting fact: even though user $d$ and $q$ have no ratings in common, they are similar in terms of concepts.

![[images/3-Apprentissage automatique/10_Recommender system/3.Collaborative filtering/svd-4.png]]

### $QP$ Factorization

**Definition (QP factorization).** Let's assume we can approximate the rating matrix $R$ as a product:

$$R \approx Q \cdot P^T$$

![[images/3-Apprentissage automatique/10_Recommender system/3.Collaborative filtering/QP-1.png]]

**Prediction.** To estimate one missing value, we define:

$$\hat{r}_{xi} = q_i \cdot p_x^T = \sum_{k} q_{ik} \cdot p_{xk}$$

where $q_i$ is row $i$ of $Q$ and $p_x$ is column $x$ of $P^T$.

![[images/3-Apprentissage automatique/10_Recommender system/3.Collaborative filtering/QP-2.png]]

**Algorithm.** SVD is not defined when entries are missing, so we compute the reconstruction error on the training set:

$$\boxed{\min_{P, Q} f(P,Q) = \sum_{(i,x) \in R} \left(r_{xi} - q_i \cdot p_x^T\right)^2 + \lambda\left[\sum_x \|p_x\|^2 + \sum_i \|q_i\|^2\right]}$$

To update the equation we use gradient descent. We compute the derivatives:

$$\nabla q_{ik} = \sum_{xi} -2 \left(r_{xi} - q_i p_x^T\right) p_{xk} + 2\lambda q_{ik}$$

and similarly for $\nabla p_{ik}$. Next we update by gradient descent:
- Initialize $P$ and $Q$, then:
  - $P \leftarrow P - \eta \cdot \nabla P$
  - $Q \leftarrow Q - \eta \cdot \nabla Q$

### Expectation Maximization

**(i) Initialization.** We build on top of a rating matrix of $1200$ users and $1200$ rated movies. The ratings range from one to five stars, mapped to integers $\{1,2,3,4,5\}$. We set $X[u,i]=0$ whenever an entry is missing.

In a realistic setting, most entries of $X$ are missing. For this reason, we define $C_u$ as the set of movies (column indexes) that user $u$ has rated, and $H_u$ as its complement (the set of remaining unwatched/unrated movies we wish to predict ratings for). We use $|C_u|$ to denote the number of observed rating values from user $u$. From the point of view of our mixture model, each user $u$ is an example $x^{(u)} = x[u,:]$. But since most coordinates of $x^{(u)}$ are missing, we need to focus the model during training on just the observed portion. To this end, we use $x_{C_u}^{(u)} = \{x_i^{(u)} : i \in C_u\}$ as the vector of only observed ratings. If columns are indexed as $\{0, \ldots, d-1\}$, then a user $u$ with rating vector $x^{(u)} = (5,4,0,0,2)$, where zeros indicate missing values, has $C_u = \{0,1,4\}$, $H_u = \{2,3\}$, and $x_{C_u}^{(u)} = (5,4,2)$.

$$[X]_{1200 \times 1200}$$

We have four additional vectors/matrices to initialize for the EM algorithm:

- The prior on each Gaussian, set uniformly:

$$p = [0.086, \ldots, 0.086]_{12 \times 1}$$

- The mean of each Gaussian, set as a random subset of twelve observations, denoted $\tilde{X}$:

$$\mu = [\tilde{X}]_{12 \times 1200}$$

- The variance:

$$var_j = \left([X]_{1200 \times K} - \mu_j\right)^2\text{.mean()}$$

- The posterior distribution, with a uniform probability assigned for every observation over all Gaussians:

$$[post]_{1200, 12} = \begin{pmatrix} 0.0833 & 0.0833 & \ldots \\ 0.0833 & 0.0833 & \ldots \\ \ldots & \ldots & \ldots \end{pmatrix}$$

**(ii) E-step.** The marginal:

$$P\left(x_{C_u}^{(u)} \mid \theta\right) = \sum_{j=1}^K \pi_j\, \mathcal{N}\left(x_{C_u}^{(u)}; \mu_{C_u}^{(j)}, \sigma_j^2 I_{|C_u| \times |C_u|}\right)$$

The posterior probability — the soft assignment of cluster $j$ to data point $u$:

$$P\left(y=j \mid x_{C_u}^{(u)}\right) = p(j \mid u) = \frac{p(u \mid j) \cdot p(j)}{p(u)} = \frac{p(u \mid j) \cdot p(j)}{\sum_{j=1}^K p(u \mid j) \cdot p(j)} = \frac{\pi_j\, N\left(x_{C_u}^{(u)}; \mu_{C_u}^{(j)}, \sigma_j^2 I_{C_u \times C_u}\right)}{\sum_{j=1}^K \pi_j\, N\left(x_{C_u}^{(u)}; \mu_{C_u}^{(j)}, \sigma_j^2 I_{C_u \times C_u}\right)}$$

To minimize numerical instability, we re-implement the E-step in the log-domain. Let $f(u,j) = \log(\pi_j) + \log\left(N\left(x_{C_u}^{(u)}; \mu_{C_u}^{(j)}, \sigma_j^2 I_{C_u \times C_u}\right)\right)$. Then, in terms of $f$, the log posterior is:

$$\begin{aligned}
\ell(j \mid u) &= \log(p(j\mid u)) = \log\left(\frac{\pi_j N\left(x_{C_u}^{(u)}; \mu_{C_u}^{(j)}, \sigma_j^2 I_{C_u \times C_u}\right)}{\sum_{j=1}^K \pi_j N\left(x_{C_u}^{(u)}; \mu_{C_u}^{(j)}, \sigma_j^2 I_{C_u \times C_u}\right)}\right) \\
&= \log\left(\pi_j N\left(x_{C_u}^{(u)}; \mu_{C_u}^{(j)}, \sigma_j^2 I_{C_u \times C_u}\right)\right) - \log\left(\sum_{j=1}^K \pi_j N\left(x_{C_u}^{(u)}; \mu_{C_u}^{(j)}, \sigma_j^2 I_{C_u \times C_u}\right)\right) \\
&= f(u,j) - \log\left(\sum_{j=1}^K \exp(f(u,j))\right)
\end{aligned}$$

**(iii) M-step.** By decomposing the multivariate spherical Gaussians into univariate spherical Gaussians as before, we can write, for $l \in C_u$:

$$\widehat{\mu_l^{(k)}} = \frac{\sum_{u=1}^n p(k\mid u)\, \delta(l, C_u)\, x_l^{(u)}}{\sum_{u=1}^n p(k\mid u)\, \delta(l, C_u)}$$

$$\widehat{\sigma_k^2} = \frac{1}{\sum_{u=1}^n |C_u|\, p(k\mid u)} \sum_{u=1}^n p(k\mid u) \left\|x_{C_u}^{(u)} - \widehat{\mu_{C_u}^{(k)}}\right\|^2, \qquad \widehat{\pi_k} = \frac{1}{n}\sum_{u=1}^n p(k\mid u)$$

where $\delta(i, C_u) = 1$ if $i \in C_u$ and $\delta(i, C_u) = 0$ if $i \notin C_u$. It is possible to vectorize the norm of the variance by calculating:

$$SSE = [\tilde{X} - \mu] \times \delta$$

where $[\tilde{X}]_{12 \times 1200}$ is a matrix in which we repeat the same observation 12 times, and $[\mu]_{12 \times 1200}$ contains the 12 different mean vectors. We multiply by $\delta$ to zero out the unknown elements:

$$[\delta]_{1200 \times 1200} = \begin{pmatrix} \text{True} & \text{True} & \ldots \\ \text{True} & \text{False} & \ldots \\ \ldots & \ldots & \ldots \end{pmatrix}$$

Finally the norm is equivalent to `sum(axis=1)`.

**(iv) Fill-in Matrix.** After several rounds of E-step and M-step, we compute the missing values, replacing the zeros in matrix $X$:

$$X_{filled} := \delta X + (1-\delta) \left\langle [post]_{1200,12} \times [\mu]_{12 \times 1200} \right\rangle$$

where $post$ is the posterior probability matrix and $\mu$ the mean matrix for our 12 clusters. Multiplying by the $(1-\delta)$ matrix sets all known ratings to zero, retaining only the unknowns.

### Multinomial VAE

**Prerequisite (Multinomial Likelihood).** Recall the pdf of the multinomial distribution:

$$\begin{aligned}
f(x_1, x_2, \ldots, x_n) &= \frac{n!}{x_1! x_2! \cdots x_k!}\, p_1^{x_1} p_2^{x_2} \cdots p_k^{x_k} \\
\sum_{i=1}^n x_i &= n \quad \text{and} \quad \sum_{i=1}^n p_i = 1
\end{aligned}$$

Taking the log of the pdf gives the log-likelihood:

$$L(p_1, p_2, \ldots, p_n \mid x) = \log\left(\frac{n!}{x_1! x_2! \cdots x_k!}\right) + \sum_{i=1}^k x_i \log(p_i)$$

**Definition (User-item interaction matrix).** Let $u \in \{1, \ldots, U\}$ index users and $i \in \{1, \ldots, I\}$ index items. The interaction matrix is the click matrix:

$$X \in \mathbb{N}^{U \times I}$$

The lowercase $x_u = [x_{u1}, \ldots, x_{uI}]^T \in \mathbb{N}^I$ is a bag-of-words vector with the number of clicks for each item from user $u$.

**VAE-CF.**

**(i) Inference.** For each user $u$, the model starts by sampling a $K$-dimensional latent representation $z_u$ from the standard Gaussian prior.

**(ii) Generative.** The latent representation $z_u$ is transformed via a non-linear function $f_\theta(\cdot) \in \mathbb{R}^I$ to produce a probability distribution over $I$ items, $\pi(z_u)$, from which the click history $x_u$ is assumed to have been drawn:

$$\pi(z_u) \approx \exp\{f_\theta(z_u)\}, \qquad z_u \sim N(0, I_K)$$

with $x_u \sim \text{Multi}(N_u, \pi(z_u))$.

![[images/3-Apprentissage automatique/10_Recommender system/3.Collaborative filtering/vae-1.png]]
*Visually the first user is mapped to $z_u$ and then mapped to the first row of the output matrix.*

**(iii) Loss function.** The objective of Multi-VAE for a single user $u$ is:

$$\mathscr{L}(\theta, \phi) = \mathbb{E}_{q_\phi(z_u \mid x_u)}\big[\log p_\theta(x_u \mid z_u)\big] - \beta\, KL\big(q_\phi(z_u \mid x_u) \,\|\, p(z_u)\big)$$

Note:
- The output of $f_\theta(\cdot)$ is normalized via a softmax function to produce a probability vector $\pi(z_u)$.
- The multinomial log-likelihood for user $u$ (conditioned on the latent representation) is:

$$\log p_\theta(x_u \mid z_u) = \sum_i x_{ui} \log \pi_i(z_u)$$

**Trick.** Regarding the parameter $\beta$, we rely on two strategies:
1. We propose using $\beta \neq 1$ because we are no longer optimizing a lower bound on the log-marginal likelihood.
2. If $\beta < 1$, the model is less able to generate novel user histories — which is fine, since we are solely interested in good recommendations, not a good generative model.
3. Heuristic: we start with $\beta = 0$, gradually increase it until we reach $1$, and record the best $\beta$.

**Prediction.**
1. First train the Multi-VAE.
2. Given a user click history $x$, rank all the items based on the un-normalized predicted multinomial probability $f_\theta(z_u)$.

**Algorithm.**

**(i) Inputs.** Let $[train\_data]_{N \times n\_items}$, where $N$ is the total number of users and $n\_items$ the number of unique items. Ratings range from $\{1, 2, \ldots, 5\}$, constrained here to $\{4, 4.5, 5\}$. More precisely, $N = 116{,}477$ users, $n\_items = 20{,}101$ items.

**(ii) Building the model.** Define the dimensions of the inference layers:

$$p\_dims = [200, 600, n\_items] = [200, 600, 20101]$$

and the generative layers:

$$q\_dims = [n\_items, 600, 200] = [20101, 600, 400]$$

During the $z$ phase:

$$z = std \times [\epsilon]_{batch \times 200} + \mu, \qquad \epsilon \sim N(0,1)$$

![[images/3-Apprentissage automatique/10_Recommender system/3.Collaborative filtering/vae-2.png]]

**(iii) Prediction.** For prediction, we look solely at the top five predictions, for example.

**(iv) Loss.** The reconstruction loss is a categorical loss.
